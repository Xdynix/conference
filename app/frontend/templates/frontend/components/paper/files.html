{% comment %} Paper files component. Edit mode: submission file upload. View mode: all files download (submission + final). Final version upload is handled by a separate modal in the detail page, not here. This component manages upload UI state and delegates the actual upload to a parent- provided handler. This keeps the component reusable and decouples it from API knowledge. Expects from parent scope: - mode: 'create' | 'edit' | 'view' - paper: Paper object with submission and final file fields - uploadSubmission(file, onProgress): async function to perform the upload The onUpload handler receives: - file: File object to upload - onProgress: callback with ProgressEvent for progress bar updates The component is hidden in 'create' mode (no paper exists yet). {% endcomment %}
