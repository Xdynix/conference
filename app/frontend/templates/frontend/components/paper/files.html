{% comment %} Paper files component. Edit modes: submission file upload (+ final upload for admin-edit with conference admin). View modes: all files download (submission + final). This component manages upload UI state and delegates the actual upload to parent-provided handlers. This keeps the component reusable and decouples it from API knowledge. Expects from parent scope: - mode: 'create' | 'edit' | 'view' | 'admin-create' | 'admin-edit' | 'admin-view' - paper: Paper object with submission and final file fields - uploadSubmission(file, onProgress): async function to perform submission upload - uploadFinal(sourceFile, viewableFile, onProgress): async function to perform final upload (admin-edit only) The component is hidden in create modes (no paper exists yet). {% endcomment %}
