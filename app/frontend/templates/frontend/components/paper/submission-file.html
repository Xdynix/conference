{% comment %} Submission file upload and display component. This component manages upload UI state and delegates the actual upload to a parent- provided handler. This keeps the component reusable and decouples it from API knowledge. Expects from parent scope: - mode: 'create' | 'edit' | 'view' - paper: Paper object with submission field - uploadSubmission(file, onProgress): async function to perform the upload The onUpload handler receives: - file: File object to upload - onProgress: callback with ProgressEvent for progress bar updates The component is hidden in 'create' mode (no paper exists yet). {% endcomment %}
