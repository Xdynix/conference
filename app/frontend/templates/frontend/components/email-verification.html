{% comment %} Email verification component with code-based flow. Requires the parent component to provide: - Turnstile methods via cfTurnstileWidget spread: - cfTurnstileReady(): Returns true if Turnstile token is available - cfRequestConfig(): Returns axios config with Turnstile header - cfTurnstileReset(): Refreshes the Turnstile token for the next API call - `errors` object for displaying form submission errors (e.g., "email already taken") in the verified state. The component accesses `errors['']`. The component uses its own `verifyErrors` object for internal verification flow errors. Example parent setup:
